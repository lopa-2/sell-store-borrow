# Sell, Store, or Borrow

A smart decision platform empowering smallholder farmers to unlock instant cash
without selling their harvest at distress prices.

## Features
- Sell/Store recommendation based on Mandi price trend + spoilage risk
- Spoilage Alert using live weather forecast (Open-Meteo)
- e-NWR-style loan simulation (70-80% of crop value)
- Voice output via Web Speech API
- Downloadable PDF loan offer

## Run locally
npm install
npm run dev

## Tech
React + Vite, Open-Meteo weather API, optional data.gov.in Mandi price API,
recharts, jsPDF, Web Speech API.
